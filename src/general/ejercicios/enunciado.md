# 📋 Enunciado - Modelo estándar Markdown

Este ejercicio muestra el **modelo B**: una estructura sencilla y mantenible basada en Markdown, sin bloques parallax.

## Enunciado

Crea una pequena actividad guiada que incluya:

- Un objetivo principal.
- Una lista de requisitos.
- Un entregable final.

## Objetivos

- Comprender la estructura de un ejercicio en formato Markdown.
- Redactar instrucciones claras para el alumnado.
- Mantener trazabilidad de entrega y evaluacion.

## Requisitos

- Definir claramente el alcance de la tarea.
- Incluir al menos 3 criterios de evaluacion.
- Entregar en formato Markdown o PDF.

## Criterios de evaluacion

- Claridad de la solucion presentada.
- Correccion tecnica de los pasos.
- Calidad de la documentacion y conclusiones.

## Entregable

Entrega un documento con:

1. Descripcion de la solucion.
2. Evidencias (capturas o resultados).
3. Conclusiones finales.

::: tip-box Consejo
Si el ejercicio es largo, divide la entrega en secciones para facilitar la correccion.
:::
